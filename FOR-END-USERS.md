# Install LaunchFlow

1. Get **`LaunchFlow-Setup-v0.7.8-x64.exe`** (see [GET-THE-APP.md](GET-THE-APP.md))
2. Double-click it
3. Click through Setup
4. Create your master password

You do **not** need the source zip, `BUILD-INSTALLER`, Visual Studio, or .NET SDK.

Requirements: Windows 10/11 64-bit, and Edge or Chrome for website automation.
